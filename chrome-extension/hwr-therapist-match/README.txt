HWR Therapist Match: Chrome side panel
=======================================

Opens Therapist Match in a panel on the right side of Chrome, next to the
Zenoti schedule. The panel stays open while you click around Zenoti or switch
tabs, and only closes when you close it.

Install (once per computer)
1. Unzip this folder somewhere it will stay (e.g. Documents). Don't delete it
   after installing; Chrome loads the extension from this folder.
2. In Chrome, go to chrome://extensions
3. Turn on "Developer mode" (top right).
4. Click "Load unpacked" and choose the "hwr-therapist-match" folder.
5. Click the puzzle-piece icon in the toolbar and pin "HWR Therapist Match".

Use
- Click the HWR icon to open the panel. Click it again, or the X at the top of
  the panel, to close it.
- Drag the panel's left edge to make it wider or narrower.

Updates
- The tool loads from https://hwr-timers.netlify.app/therapist-match-panel/,
  so changes published to the site show up the next time the panel opens.
  You only need to reload this folder if the extension files themselves change.
